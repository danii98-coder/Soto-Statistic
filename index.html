¿Qué significa cada resultado?

Tamaño de muestra: Indica la cantidad de elementos que deben formar parte de una muestra para realizar un estudio estadístico bajo los parámetros establecidos.

Desviación estándar: Indica qué tan dispersos se encuentran los datos respecto a su media.

Fórmulas utilizadas

  • n = (N·Z²·p·q) / ((N−1)·E² + Z²·p·q)
  • x̄ = Σx / n
  • σ² = Σ(x − x̄)² / n   σ = √σ²
  • s² = Σ(x − x̄)² / (n − 1)   s = √s²
